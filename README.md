## Beer Rating EDA & Feature Engineering

Разведочный анализ данных (EDA) и инженерия признаков для датасета отзывов о пиве. Цель — выявить факторы, влияющие на пользовательский рейтинг продукта.

## Данные
- Источник: открытый датасет отзывов (BeerAdvocate / RateBeer)
- Объем: 37 000+ отзывов
- Целевая метрика: `avg_review` (средний рейтинг продукта)

## Задачи
- Сформулировать гипотезы о влиянии характеристик продукта (крепость, пивоварня) и профиля пользователя (возраст, пол) на рейтинг.
- Провести очистку данных: обработка выбросов, пропусков, дубликатов.
- Выполнить feature engineering: кодирование категориальных признаков, отбор значимых факторов.
- Визуализировать зависимости и проинтерпретировать результаты.

## Методы
- Обработка выбросов: метод Z-score
- Обработка пропусков: `SimpleImputer`
- Кодирование: One-Hot Encoding
- Отбор признаков: `SelectKBest`
- Визуализация: Matplotlib, Seaborn
- Статистика: доверительные интервалы, корреляция Пирсона

## Ключевые результаты
- Различия в средних оценках лучших и худших продуктов статистически значимы (подтверждено через доверительные интервалы).
- Линейная зависимость рейтинга от крепости (ABV) слабая, но выявлены сильные нелинейные паттерны по пивоварням.
- Пол и возраст пользователя не оказывают статистически значимого влияния на рейтинг.

## Инструменты
- Python
- Pandas, NumPy
- Scikit-learn (`SimpleImputer`, `SelectKBest`)
- Matplotlib, Seaborn
